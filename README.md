# 🏥 MedIntel - Hospital Management System

A modern full-stack Hospital Management System built using **FastAPI**, **Next.js**, **PostgreSQL**, and **TypeScript**.

---

# Features

## Authentication

- JWT Authentication
- Secure Login
- Protected Routes

## Dashboard

- Live Statistics
- Interactive Charts
- Hospital Overview

## Patients

- Create Patient
- View Patients
- Update Patient
- Delete Patient
- Search Patients

## Doctors

- Create Doctor
- View Doctors
- Update Doctor
- Delete Doctor
- Search Doctors

## Appointments

- Schedule Appointment
- Update Appointment
- Cancel Appointment
- Search Appointments

## Medical Records

- Create Medical Record
- Update Medical Record
- Delete Medical Record
- Patient Medical History

# Installation

## Backend

```bash
cd backend
uvicorn app.main:app --reload
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```
